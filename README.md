## 📂 Project Architecture

This repository contains a decoupled full-stack architecture:

```text
portfolio/
├── client/                     # React.js Frontend (Vite)
│   ├── public/assets/          # Project mockups & visual assets
│   ├── src/
│   │   ├── components/         # Glassmorphic UI Components (Hero, Services, Skills, Projects, Experience, Contact)
│   │   ├── data.js             # Centralized profile & skillset data store
│   │   ├── App.jsx             # React App Root & state management
│   │   └── index.css           # Glassmorphism Design System & Theme CSS
│   └── vite.config.js
│
└── server/                     # Node.js + Express REST API Backend
    ├── db/
    │   ├── schema.sql          # Full MySQL Database Schema & Seed Data
    │   └── connection.js       # MySQL connection pool + fallback memory store
    └── index.js                # Express API Endpoints (/api/profile, /api/services, /api/skills, /api/projects)
```

## ⚙️ Local Installation & Setup Guide

### 1. Prerequisites
- Node.js (v18+)
- npm or yarn

### 2. Backend API Setup
```bash
cd server
npm install
npm start
```
> The API server will start on `http://localhost:5000`.

### 3. Frontend App Setup
In a second terminal tab:
```bash
cd client
npm install
npm run dev
```
> Open `http://localhost:5173/` in your browser to view the interactive portfolio!
